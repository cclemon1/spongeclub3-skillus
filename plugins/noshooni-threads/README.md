# 노슈니 스레드 3종

**한 줄:** 계정 코어 잡기 → 소재 쌓기 → 후킹 글쓰기까지, 스레드 운영을 한 흐름으로 묶은 스킬 3종

## 어떤 플러그인인가요
남이 만든 글쓰기 스킬을 그대로 쓰면 글은 잘 나오는데 내 글 같지가 않다. 스킬에는 어떻게 쓰는지는 있어도 누가 쓰는지는 없기 때문이다.

이 묶음은 누가 쓰는지(코어)와 무엇을 쓸지(소재)를 먼저 파일로 만들어 두고, 그걸 바탕으로 글을 쓰게 한다. 방식은 스킬에, 재료는 내 파일에.

## 뭘 해주나
| 순서 | 스킬 | 하는 일 | 남는 것 |
|---|---|---|---|
| 1 | threads-core | 인터뷰로 운영 목적·타겟·관통 관점·컨셉·말투·전환 목적지를 잡는다 | `my-threads-core.md` |
| 2 | threads-material | 기록 추적과 인터뷰로 서사 재고를 쌓고, 유명·최신 사례를 붙여 소재 카드로 엮는다. 벤치마크 정찰과 옛 글 재발행 판정도 | `my-story-bank.md` |
| 3 | threads-writing | 훅 후보 3개 → 칸 단위 본문 → 발행 후 분석. 인스타 카드뉴스 변환까지 | 스레드 본문 |

코어 파일을 대화에 같이 올리면 소재·글쓰기 스킬이 그 계정의 말투와 전환 목적지를 규칙으로 삼는다. 셋 중 하나만 써도 된다.

## 설치
클로드 코드에서 두 줄이면 돼요. 첫 줄은 처음 한 번만.

```
/plugin marketplace add selfishclub/spongeclub3-skillus
/plugin install noshooni-threads@skillus
```

설치한 뒤엔 "스레드 코어 잡아줘", "소재 좀 파내줘", "스레드 글 써줘"처럼 말하면 알맞은 스킬이 켜져요.
