# sponge-security

**한 줄:** 깃허브에 작업한 내용을 올리기 전에 시크릿 키값이나 내 정보가 새는지 봐주고, 남이 만든 스킬은 깔기 전에 검사해 주는 보안 심리 캐어 스킬

## 어떤 스킬인가요
바이브 코딩하다 보면 "이거 올려도 되나?" "이 스킬 깔아도 되나?"가 제일 불안했어요. 
5회차 보안 점검과 6회차 특강 체크 리스트를 자동화했고, 결과를 지금 당장/이번 주/나중에 세 단으로 주면서 맨 위에 안심 등급 🟢🟡🔴을 붙여요. 
뭘 봤고 뭘 못 봤는지도 같이 적어 줘서 막연한 불안이 줄어드는 일종의 보안 심리 캐어, 실제 평가는 써보시고 평가해주세요

## 뭘 해주나
(스킬 다운 로드시)
내려받은 스킬은 실행 없이 읽어서 스폰지클럽 규범(키 요청 금지·삭제 금지·자동 push 등) 대조표를 냄. 
(베포전 점검시)
git push·vercel 전에 시크릿, .env.local 값, 내 이메일·전화·이름, 열린 RLS, 어드민 인증 유무를 점검. 
로컬 편집기에서 내 정보·예외·규칙 관리. 훅 설치하면 push 직전에 자동으로 돎.

## 더 하고 싶은 말
내 정보는 내 PC의 config.json에만 남고 어디로도 안 갑니다. 
시크릿은 값 대신 해시만 저장해요. 이 스킬을 스폰지 보안으로 검사하면 규칙 카탈로그 때문에 BLOCK 힌트가 뜨는데, 그게 정상입니다.
