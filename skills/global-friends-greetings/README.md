# global-friends-greetings

**한 줄:** 해외 거래처나 외국 친구들에게 명절 인사, 날짜·톤·보낼 시각까지 대신 챙겨주는 스킬이에요.

## 어떤 스킬인가요
해외 거래처에 명절 인사 보낼 때 쓰는 스킬이에요. 이드가 올해 언제인지, 이날 "Happy"를 붙여도 되는 날인지 매번 검색하기 지쳐서 만들었어요. 93개국 기념일 220건이 들어 있어요.

## 뭘 해주나
"다음 달에 인사 보낼 데 있어?" 하면 나라별로 뽑아줘요. "사우디 거래처한테 이드 인사말 써줘" 하면 이메일이랑 왓츠앱 문안을 따로 써주고요. 한국시간 몇 시에 눌러야 현지 아침에 도착하는지까지 계산해줘요.

## 더 하고 싶은 말
만들면서 제일 놀란 건 11월 11일이었어요. 영국·캐나다는 현충일이라 "Happy"가 금지인데, 폴란드는 독립기념일이라 축하해야 해요. 한 문안 돌리면 양쪽 다 틀리는 거죠. 앤작데이의 "ANZAC"은 호주에서 상업적 사용이 법으로 제한된 단어고요.

정작 제일 자주 쓰는 건 "연락해봐야 소용없는 때"예요. 러시아는 12/29~1/11, 이탈리아는 8월 통째로 멈춰요. 8월에 프랑스로 보낸 메일은 9월에 읽히더라고요.

파이썬 3.9 이상만 있으면 되고 설치할 패키지는 없어요.
