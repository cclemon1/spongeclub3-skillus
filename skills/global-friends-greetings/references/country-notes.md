# 국가별 주의사항

`data/countries.csv`가 기계가 읽는 표라면, 이 문서는 **사람이 판단할 때 보는 메모**다.
명단을 어떻게 쪼갤지, 언제 연락을 포기할지, 연말에 뭐라고 쓸지 — 세 가지를 다룬다.

## 목차
- §1 절대 같은 명단에 넣으면 안 되는 조합
- §2 업무가 멈추는 기간 — 연락해도 답이 안 오는 때
- §3 연말 인사 국가별 문구
- §4 만능 축하 표현 세 개
- §5 매년 다시 확인해야 하는 항목

## 1. 절대 같은 명단에 넣으면 안 되는 조합

수신자에게 보이지 않는 BCC라도 **문안을 돌려쓰는 것 자체가 사고**다. 한쪽에 맞춘 표현이
다른 쪽에는 정확히 반대 의미가 된다.

| 조합 | 왜 |
|---|---|
| **아르메니아 ↔ 아제르바이잔** | 나고르노카라바흐. 11/8과 4/24는 서로의 상처 |
| **러시아 ↔ 우크라이나** | 전쟁 중. 어떤 언어로 쓰느냐 자체가 정치적 표명 |
| **인도 ↔ 파키스탄** | 8/14와 8/15는 분단의 양쪽. 2/5 카슈미르 연대의 날은 반인도 표명 |
| **중국 ↔ 대만** | 10/1과 10/10. 간체·번체 표기까지 갈린다 |
| **한국 ↔ 일본** | 3/1, 8/15. 한국 기업이라면 특히 8/15에 일본 거래처에 아무것도 보내지 않는 게 안전 |
| **이스라엘 ↔ 아랍권** | 이스라엘 독립기념일은 아랍권의 나크바(추방) 기념일과 겹친다 |
| **모로코 ↔ 알제리** | 11/6 녹색행진일. 서사하라 문제 |
| **세르비아 ↔ 크로아티아** | 8/5는 크로아티아의 승리이자 세르비아의 애도. 11/18 부코바르 |
| **세르비아 ↔ 코소보** | 세르비아 파트너가 보는 자료에 코소보를 국가로 표기하지 않는다 |
| **그리스 ↔ 터키** | 3/25·10/28 그리스 국경일은 반오스만 서사. 키프로스 미해결 |
| **불가리아 ↔ 터키** | 3/10 해방기념일도 반오스만 |
| **헝가리 ↔ 루마니아·슬로바키아** | 트리아농, 트란실바니아, 헝가리계 소수민족 |
| **폴란드 ↔ 러시아** | 카틴, 1939년 |
| **캄보디아 ↔ 베트남** | 1/7 |
| **베트남 국내 ↔ 재외 베트남계** | 4/30은 통일기념일이자 "검은 4월" |
| **페루 ↔ 칠레** | 6/7·10/8은 태평양 전쟁 기념일. 같은 문안 재사용 금지 |
| **일본 대상 콘텐츠 ↔ 중국** | 9/18·12/13 전후엔 일본색 콘텐츠를 잠시 내린다 |

**운영 원칙: 국가당 명단 하나.** "유럽", "중동", "CIS" 같은 광역 발송은 하지 않는다.
템플릿을 하나 더 만드는 비용이, 잘못 간 인사 하나의 비용보다 훨씬 싸다.

## 4. 만능 축하 표현 세 개

축하할 날인지 조심할 날인지 애매할 때 쓸 수 있는 표현들. 외워둘 값어치가 있다.

- 그리스어 **Χρόνια Πολλά** (Chronia Polla) — "오래 사시기를". 생일·명절·국경일 전부에 쓴다
- 루마니아어 **La mulți ani** — 같은 뜻, 같은 용법
- 러시아어 **С праздником!** (S prazdnikom) — "명절을 맞아".
  튀르크권 등가 표현: *Bayramınız mübarək* (AZ), *Merekeñiz qutty bolsyn* (KZ),
  *Baýramyňyz gutly bolsun* (TM)

영어에서 같은 자리를 메우는 문장은 **"Wishing you a wonderful year ahead"** 하나다.
종교·정치 전제가 없고, 이 목록의 모든 시장에서 통한다.

## 5. 매년 다시 확인해야 하는 항목

데이터가 낡으면 틀리는 지점들. 연말에 다음 해 데이터를 채울 때 이 목록부터 본다.

**날짜가 매년 움직인다**
- 이슬람력 전체 (Umm al-Qura 기준 + 국가별 ±1일)
- 음력 (춘절·설날·뗏·중추절)
- 힌두력 (디왈리·홀리·두세라)
- 정교회 부활절 (율리우스력 계산)
- 노루즈 (테헤란 기준 춘분 — 3/20 또는 3/21)

**정부가 매년 새로 고시한다 — 전년도 자료는 틀릴 수 있다**
- 중국 국무원 공휴일 통지
- 인도네시아 SKB 3 Menteri (장관합동령)
- 베트남 뗏 연휴 범위 (총리 결정)
- 홍콩 General Holidays 관보 (전년 5월경)
- 싱가포르 MOM, 말레이시아, 대만 DGPA, 방글라데시 내각사무처, 라오스 총리령
