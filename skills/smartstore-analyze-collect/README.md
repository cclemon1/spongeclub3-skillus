# smartstore-analyze-collect

**한 줄:** 스마트스토어 주소를 주면 홈과 대표 상품을 살펴보고, 나중에 분석할 수 있도록 화면 증거와 확인 사실을 정리해 주는 스킬

## 어떤 스킬인가요
스마트스토어를 평가하기 전에 공개 화면에서 확인할 수 있는 사실과 캡처를 먼저 모아주는 스킬이에요. 홈, 상품 목록, 대표 상품을 둘러보고 확인한 것과 확인 못 한 것을 나눠 기록해요.

## 뭘 해주나
주소를 주면 홈과 카테고리, 대표 상품 최대 2개를 확인하고 evidence.md와 캡처 폴더로 정리해줘요. 로그인이나 우회는 하지 않고, 점수나 진단도 붙이지 않아요.

## 더 하고 싶은 말
기존 버전에서 내부 프로젝트 기준표와 추출 코드를 걷어내고, 누구나 쓸 수 있는 공개 화면 수집 기능만 남긴 간소화 버전입니다.

## 설치
