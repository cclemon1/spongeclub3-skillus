# gooddaddy-report

**한 줄:** 주말에 애랑 어디 갈지, 낮잠 시간까지 맞춰 코스 짜서 와이프한테 보낼 카드로 만들어주는 스킬

## 어떤 스킬인가요
주말마다 "애 데리고 어디 가지" 검색만 한 시간씩 하다가 만들었어요. 동네·아이 월령·낮잠 시간만 한 번 알려주면, 그 주말 날씨랑 거리를 보고 계획을 짜서 와이프한테 카톡으로 보낼 카드 5장으로 뽑아줘요.

## 뭘 해주나
- 날씨·기온·미세먼지·거리 보고 장소 5곳 추천 (실내 대안 포함)
- 장소마다 아기랑 먹을 식당 (노키즈존 거르고, 애는 뭐 먹이면 되는지까지)
- 1순위 하루 시간표: 1시간 넘게 가면 낮잠 시간에 출발, 오픈런이면 개장 30분 전 도착, 점심 11:30 전, 귀경 정체 전 귀가
- 차 없으면 지하철·유모차 엘리베이터 출구 기준으로
- 1/5 번호 붙은 카드라 카톡에 순서대로 올리면 끝

## 더 하고 싶은 말
Node랑 크롬(또는 엣지)만 있으면 돌아가요. 카카오 REST 키 넣으면 이동시간이 더 정확해져요. 자동으로 보내진 않으니까 이미지는 직접 보내주세요.
